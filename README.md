# Annuaire Artisans & Pros (données publiques)

Fichiers par département des entreprises **actives** des métiers du bâtiment et des services, utilisés par l'appli Android « Artisans & Pros » (BY INNOVATION) pour afficher tout de suite les artisans près de chez soi, même hors ligne.

- Source : base Sirene de l'INSEE, via l'API publique recherche-entreprises.api.gouv.fr (DINUM). Licence ouverte Etalab 2.0.
- Seules les entreprises en diffusion publique sont reprises (les entreprises en diffusion partielle sont exclues).
- Mise à jour : une fois par mois.
- Format : `v1/<département>/<code NAF>.json` ; `v1/<département>/index.json` ; `v1/index.json`.
